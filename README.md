# 黄金现货观察台

用于日常观察国际黄金现货、国际黄金期货、中国上金所 Au(T+D) 和工商银行如意金积存价格的本地网页。

## 功能

- 国际现货参考：新浪财经 `hf_XAU` 伦敦金。
- 国际期货参考：Yahoo Finance `GC=F`。
- 中国黄金参考：上海黄金交易所 `Au(T+D)` 延时行情。
- 工商银行如意金积存：主动积存价、赎回价。
- 汇率：Yahoo Finance `CNY=X`，失败时使用 Frankfurter `USD/CNY`。
- 数据源失败时自动切换备选通道；全部失败时保留上次成功缓存并标注缓存时间。

## 运行

```bash
npm start
```

打开：

```text
http://localhost:5177
```

## 说明

本页面仅用于行情观察和辅助决策，不构成投资建议。不同数据源的报价口径不同，例如国际现货 `hf_XAU` 和期货 `GC=F` 不应混作同一价格。
